Installation Instructions

How to Sideload Android APK

  1. Tap "Download Android APK" above. If Google Chrome shows a prompt stating "File might be harmful", tap Download anyway (standard notice for apps downloaded outside Google Play).
  2. Open the downloaded file from your device's notification tray or Downloads folder.
  3. Allow Unknown Sources: If prompted by Android Settings, toggle "Allow from this source" to grant your browser permission to install APK packages.
  4. Tap "Install": BiteLens will install instantly without root requirements or special permissions.

How to Install PWA to Home Screen

  • On Android (Chrome / Brave / Firefox): Open BiteLens, tap the browser menu (three dots in top-right), and select "Install app" or "Add to Home Screen".
  • On iPhone / iPad (Apple Safari): Open BiteLens in Safari, tap the Share icon (square with upward arrow at bottom), scroll down, and tap "Add to Home Screen".
  • On Desktop (Chrome / Edge): Click the Install icon located at the right side of the URL address bar to install BiteLens as a standalone desktop window.
